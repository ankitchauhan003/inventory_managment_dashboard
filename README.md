# 📦 Inventory Management System Dashboard

## 📌 Project Overview
This project is an Inventory Management System Dashboard created using Microsoft Excel.
It helps track products, monitor available stock, calculate inventory value, and identify low-stock products.

## 🎯 Project Objectives
- Track total products.
- Calculate available stock.
- Calculate total inventory value.
- Identify low-stock products.
- Visualize inventory data using charts.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts & Data Visualization

## 📊 Key Features
- Total Products
- Total Available Stock
- Total Inventory Value
- Low Stock Products
- Category-wise Inventory Value
- Product-wise Available Stock
- Stock Status Summary

## 🧮 Excel Formulas Used
- COUNTA
- SUM
- COUNTIF
- IF
- Basic Arithmetic Formulas

## 📈 Dashboard Charts
- Category-wise Inventory Value
- Product-wise Available Stock
- Stock Status Doughnut Chart

## 💡 Learning Outcomes
- Practiced Excel formulas.
- Learned inventory data analysis.
- Created an interactive-style dashboard.
- Improved data visualization skills.
